# Phase 2A 実走確認チェックリスト（同乗者用）

作成日：2026年8月19日

---

## ⚠ 必ず最初に読んでください

**このチェックリストは、運転者ではなく同乗者が操作・記録してください。**

- 運転者は運転に専念してください。走行中に画面を注視したり、スマートフォンを操作したりしないでください。
- 確認・記録・スクリーンショット・メモは、すべて同乗者が行います。同乗者がいない場合は、**必ず安全な場所に停車してから**確認してください。
- 「音声で案内されたか」「違和感がなかったか」は運転者の感覚で構いませんが、画面を見て確認する項目は同乗者が担当してください。
- 何か危険を感じた場合は、チェックを中断し、安全を最優先してください。

## 事前準備（出発前・停車中に）

- [ ] `js/config.js` のMapboxトークンが自分のトークンに差し替わっている
- [ ] iPhoneのホーム画面に追加したアイコンから起動している（Safari直接ではなく全画面表示になっていること）
- [ ] 目的地を検索し、候補一覧から正しい場所を選べる
- [ ] 「ナビ開始」を押すとルートが表示され、画面下部のナビパネルに「ナビ未開始」以外の表示（道路名・アイコンなど）が出る
- [ ] 音声で「ナビを開始します」と聞こえる
- [ ] 車のシガーソケット等で給電されている（GPS＋画面点灯で電池消費が早いため）

## 走行中の確認項目（同乗者が確認）

### 実走用ナビパネル（画面下部）

- [ ] 方向アイコンが表示され、実際に曲がる方向と一致している
- [ ] 「未知の曲がり方」の場面で、変な形のアイコンではなく、直進矢印（フォールバック）が出た場合はその旨をメモする（誤りではないが、記録しておくとPhase 2Bの改善材料になる）
- [ ] 残り距離・残り時間・到着予定時刻が表示されている
- [ ] 残り距離が急に増える（後退して見える）ことがないか
- [ ] 道路名が実際の道路と大きく違っていないか
- [ ] 画面の文字が走行中でも読める大きさ・コントラストか（昼間・トンネル内・夜間でそれぞれ確認できると尚良い）

### SmartLane車線案内

- [ ] 車線案内が表示されているとき、実際の道路の車線数・形状とおおまかに合っているか
- [ ] 「参考程度」「取得できません」等の控えめな表示のときに、赤い大きなエラーのような見せ方になっていないか
- [ ] HIGH/MEDIUM表示のときに音声でも車線案内が聞こえるか
- [ ] LOW/参考表示のときは車線の音声案内が**流れない**こと（標準の右左折案内だけが流れること）

### 標準の右左折音声案内

- [ ] 一般道で、交差点の手前（700m/300m/100m付近）で案内が聞こえるか
- [ ] 高速道路で、出口・分岐の手前（2km/1km/500m付近）で案内が聞こえるか
- [ ] 同じ案内が短時間に何度も重複して流れていないか
- [ ] 案内文が不自然に長すぎたり、聞き取りにくかったりしないか

### 到着判定

- [ ] 目的地付近に着いたとき、しばらく走ってから「目的地周辺です。ナビを終了します」と案内されるか（近づいた瞬間に即終了していないか）
- [ ] 目的地の近くを高速で通過しただけのとき、誤って「到着」にならないか（例：目的地のそばの幹線道路を素通りするケース）
- [ ] 到着後、ナビパネルが「到着」の表示に変わり、それ以上の右左折案内・再ルートが行われないか

### 自動再ルート

- [ ] わざとルートを外れたとき、しばらくして自動で再検索されるか
- [ ] 再ルート中、画面に「ルートから外れました。再検索中…」のような分かりやすい表示が出るか
- [ ] 電波の悪い場所で連続してルートを外れても、再検索が無制限に繰り返されず、どこかで「取得できません」といった案内に切り替わるか（画面上部のオレンジ色のバナー表示を確認）

### 通信・GPSの状態表示

- [ ] トンネルなどでGPSが一時的に取れなくなっても、ナビ全体が終了せず、復帰後は普通に案内が再開するか
- [ ] 電波の悪い場所で、技術的なエラー文（英語のエラーメッセージ等）ではなく、日本語の分かりやすい案内（例：「オフラインです」）が出るか

### 画面消灯・音量

- [ ] 走行中に画面が自動で消えないか
- [ ] バックグラウンドにしてから戻したとき、画面が消えない状態に復帰するか

## 走行後の確認（停車後、または帰宅後）

- [ ] 「ログ書き出し」で走行ログをダウンロードできる
- [ ] `stats.html`（集計を開く）で、今回の走行が反映されている
- [ ] 気になった場面（変なアイコン・不自然な案内・誤った到着判定など）を、日時・場所・状況とあわせてメモしておく
